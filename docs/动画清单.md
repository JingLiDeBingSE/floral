# 动画清单

Floral 的动效审计。分三部分：已经有的、建议补的、明确不做的。

> 审查结论与修复优先级见 [动画审查.md](动画审查.md)。

补的时候统一用这套参数，别各写一套：

```
进入   cubic-bezier(0.23, 1, 0.32, 1)      强 ease-out
离开   cubic-bezier(0.4, 0, 1, 1)          稍快
面板   180ms        按钮   80–120ms         文字  140ms
恒定运动（唱片 / 加载环 / 进度）用 linear，不加缓动
只动 opacity 和 transform，别动 width/height/top/left
```

## 二、建议补（8 项，按价值排序）

### P0-1 面板出现/消失动画 ✅ 已完成

**现状**：四个面板全是瞬间弹出

```cpp
if (g_settingsOpen) DrawSettings(W, H);   // 无 t，无 alpha
```

**做法**

- 180ms，`ease-out`
- 缩放 `0.96 → 1` + 透明度 `0 → 1`
- 缩放中心 = 触发按钮（音质/音量/一起听）；设置是全屏模态，居中
- 关闭 140ms 反向
- 遮罩单独 150ms 淡入

**涉及**：设置面板 `DrawSettings`、音质面板、音量面板、一起听面板

---

### P0-2 封面加载淡入 ✅ 已完成

**现状**：占位渐变 → 真图硬替换，每张图加载完闪一下

```cpp
DrawBitmapRounded(e, r, rad);      // 直接铺满，无过渡
```

**做法**：150ms 交叉淡入，占位在下、真图 alpha `0 → 1`

**涉及**：`DrawCoverArt`、`DrawDisc`

**备注**：这是每天看几十次的地方，收益最高

---

### P0-3 按钮按下反馈

**现状**：只有 hover 变色，没有按下态。`WM_LBUTTONDOWN` 只用来启拖拽

**做法**

- 按下：`scale 0.97` 或亮度 −5%，**80ms**
- 松开：回弹 **120ms**
- 只对"可点区域"生效，拖拽类（进度条、音量条、滚动条）不做缩放

**涉及**：标题栏按钮、设置里的按钮、播放控制（上/下/播放）、音质/音量/一起听入口

---

### P0-4 Toast 淡入淡出 ✅ 已完成

**现状**：硬出现、到点硬消失

```cpp
if (GetTickCount64() - g_settingsMsgAt < 5000) { ... }   // 无渐隐
```

**做法**

- 淡入 180ms + 上移 6px
- 最后 300ms 淡出
- 消失用 `ease-in`（离开比进入快）

**涉及**：`SettingsToast`、`TogToast`

---

### P1-5 切歌文字过渡 ✅ 已完成

**现状**：标题 / 歌手 / 专辑三行整体硬切

**做法**：两段——旧文字 0.13s 滑出淡出（ease-in 加速离开），新文字 0.16s 从另一侧滑入淡入（ease-out 减速落位），逐行错开 30ms；方向跟切歌走（下一首往左、上一首往右）。位移取整到像素，避免亚像素抗锯齿每帧抖

**涉及**：`DrawPlayerPage` 右侧信息区

---

### P1-6 播放/暂停图标切换 ✅ 已完成

**现状**：三角形 ⇄ 双竖线直接换图形

**做法**：**几何形变**，160ms——两个四边形同时插值：三角形右顶点拆开长成右边竖条（这一块在播放态是零面积），三角形主体收成左边竖条。全程实心、无淡入淡出，所以没有空帧也没有叠影；参数是一个标量，连点会从当前形状反向，天然可打断。缓动 smoothstep

**涉及**：播放按钮绘制

---

### P2-7 主题切换颜色过渡

**现状**：15 个颜色字段瞬间替换，差异大的主题切换时像闪一下

**做法**

- 200ms 颜色 lerp
- 占位渐变等插值结束再重建，否则会抖

**涉及**：`theme.cpp` 的 `Apply` + `UI::*` 读取处

**备注**：低频操作，优先级不高

---

### P2-8 进度条拖动点位

**现状**：拖动时圆点完全跟手（正确），松手没有落定感

**做法**：只让圆点带 60ms 滞后，进度主体保持 1:1

**涉及**：播放页进度条

---

## 三、明确不做

| 位置 | 原因 |
|---|---|
| 托盘图标点击 | 系统行为，别抢 |
| 键盘滚动（↑↓ PgUp/PgDn） | 每天上百次的操作用，加动画等于拖慢 |
| 滚动条 hover 变色 | 要么 <100ms 看不见，要么就是干扰 |
| 窗口最小化 / 关闭 | 交给系统 |
| 列表滚动本身 | 已有缓动，再加会糊 |

判断标准：**一天触发上百次的操作不加动画**；只给"偶尔发生、需要解释发生了什么"的地方加。
