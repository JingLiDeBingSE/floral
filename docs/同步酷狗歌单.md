# 同步酷狗「我喜欢」

## 为什么不是一个 exe 搞定

酷狗接口的门槛不在 HTTP，而在协议层：

- **Android 签名**：`MD5(盐 + 排序参数 + 请求体 + 盐)`
- **SID / EDT 行为指纹**：RSA-OAEP 加密的 AES 密钥 + AES-CBC 加密的鼠标轨迹/滚动/WebGL 指纹
- **设备标识**：`mid`、`dfid`、`guid` 的生成规则

这些在 [`KuGouMusicApi`](https://github.com/MakcRe/KuGouMusicApi) 里都实现了。自己往 C++ 里搬成本极高，而且酷狗一改就全废。

所以架构是：**C++ 只管画界面，Node 侧车只管连酷狗**。参考项目 [Folia](https://github.com/chthollyphile/folia-major) 的 Web 版也是这个思路（Electron 版则是把 Node 模块内嵌进主进程）。

```
C++ 界面  ←── kugou-likes.tsv / covers/ ──  Node 导出脚本  ──HTTP──>  KuGouMusicApi  ──>  酷狗
```

## 首次配置

```powershell
# 1. 拉取侧车并装依赖（只需一次）
git clone --depth 1 https://github.com/MakcRe/KuGouMusicApi.git kugou-api
cd kugou-api
npm install
cd ..

# 2. 启动侧车（保持这个窗口开着）
cd kugou-api
$env:PORT='3000'; node app.js
```

## 同步歌单

**第一步 · 扫码登录**（只需一次，登录态存在 `kugou-session.json`）

```powershell
node kugou-login.js
```

会生成 `kugou-qr.png`，用**酷狗 App → 扫一扫**扫它。脚本自动轮询，成功后存下 `token` / `userid`。

**第二步 · 抓歌单**

```powershell
node kugou-fetch.js
```

拉取 `/user/playlist`，找到「我喜欢」，再拉全部曲目，存到 `kugou-likes.json`。

**第三步 · 导出成 C++ 能读的格式**

```powershell
node kugou-export.js        # 默认下载前 150 首的封面
```

产出：

- `kugou-likes.tsv` —— `歌名 \t 歌手 \t 专辑 \t 秒数 \t 封面路径`
- `covers/*.jpg` —— 封面图

**第四步 · 打开播放器**

```powershell
cd cpp
.\build.ps1 -Run
```

## 接口备忘

| 用途 | 接口 |
|------|------|
| 二维码 | `GET /login/qr/key` → 返回 `qrcode` + base64 图 |
| 轮询扫码 | `GET /login/qr/check?key=<qrcode>` → `status` 0过期/1等待/2待确认/4成功 |
| 用户歌单 | `GET /user/playlist` |
| 歌单曲目 | `GET /playlist/track/all?id=<global_collection_id>` |

### 两个坑

**1. cookie 里的空格**

`cookie=token=xxx; userid=xxx`（分号后有空格）服务端解析不出来，会返回 `error_code 20017`。

**传参时要带 `;` 不带空格**，或者干脆把 `userid`、`token` 单独作为 query 参数再传一份：

```
/user/playlist?cookie=token%3Dxxx%3Buserid%3Dxxx&userid=xxx&token=xxx
```

**2. 「我喜欢」不是第一个歌单**

`/user/playlist` 返回里：

| 名称 | listid | is_def | 首数 |
|------|--------|--------|------|
| 默认收藏 | 1 | 1 | 8 |
| **我喜欢** | **2** | **2** | **2000** |

按 `is_def == 1` 选会选到「默认收藏」。要按 `listname == '我喜欢'` 或 `is_def == 2` 取。

## 字段映射

歌单曲目接口返回的字段和直觉不太一样：

| 需要的 | 实际字段 |
|--------|----------|
| 歌名 | `remark`（`name` 是「歌手 - 歌名」） |
| 歌手 | `singerinfo[].name`（数组，多歌手用「、」连接） |
| 专辑 | `albuminfo.name` |
| 时长 | `timelen`（毫秒） |
| 封面 | `cover`，URL 里带 `{size}` 占位符，替换成 `400` 即可 |
| 唯一标识 | `hash` / `mixsongid` / `album_audio_id` |
