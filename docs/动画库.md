# 动画库（备选方案 / 暂时没用的点子）

记录讨论过但没采用的动画方案，方便以后翻。

---

## 1. 页面分解（cell dissolve）

**用途**：歌单页 → 歌曲页的退场。

**做法**：把内容区切成 26px 的格子（约 850 格），每格独立按距离 + 随机扰动决定延迟：

```
dc     = 格子到点击位置的距离 / 屏幕对角线
rnd    = 每格固定的伪随机数（避免逐帧闪烁）
delay  = dc * 0.34 + rnd * 0.22
p      = (t - delay) / 0.44
e      = 1 - (1-p)³
size   = 26 * (1 + 0.08 * e)     // 轻微重叠，避免网格缝
FillRect(格子, UI::BG, e)
```

**效果**：页面从点击处向外被一格一格吃掉。

**为什么暂时不用**：整体观感偏"特效"，和这个播放器安静的气质不太合。已实现过一版，代码见提交历史。

**如果再用**：把格子调大到 40px 以上、延迟范围收窄，会克制很多。

---

## 2. 真正的"像素分解"（需要离屏快照）

上面的方案是"用背景色盖住"，内容本身没动。真要做内容被吹散的效果，需要：

1. 转场开始瞬间把当前画面渲染进一张离屏位图
2. 每帧从这张位图按格子取样，每格加位移 + 旋转 + 透明度衰减

**拦路的地方**：`Bind()` 换渲染目标会释放并重建所有封面位图画刷（几百张），代价太大。
除非为封面单独维护一份 CPU 侧位图，否则不划算。

---

## 3. 缩放淡出（当前采用）

页面整体放大到 1.02 并淡成背景色，260ms，配合加载圈的缩放入场。

**优点**：安静、和产品气质一致、开销几乎为零。
**注意**：缩放中心用窗口中心，不要用点击点——页面级转场不该有方向性。
